# Aurelia - Chronos Vault

Luxury Watch Collector & Horology Timepiece Showcase.

A lightweight, responsive web application for collectors to track, filter, and showcase their timepiece collection.

## Features
- **Collection Analytics**: Real-time tracking of total watches, portfolio value, and movement breakdown.
- **Interactive Showcase**: Dynamic gallery with live filtering by movement type and search by brand/model.
- **Management Tools**: Add new timepieces with specifications and toggle favorites.
- **Responsive Design**: Optimized for desktop, tablet, and mobile viewing.

## Deployment
Hosted on Vercel.
